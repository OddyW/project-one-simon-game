# Project Name
Simon Game
## Technologies Used
The game was made with HTML, CSS and JavaScript.
## Description
This is unit 1 Project for GA Software Engineering Bootcamp.

Devoloping a website game using the tools taught in class, I made a Simon game.

Simon is a simple random sequenece generator game by showing 4 colored tiles with unique sounds on each of them, the player will have to match that sequence by pressing on the correct tiles that were highlighted by the game. It is a game of focus and memorization.

the longer the sequence gets, the higher the score!
## User Stories
1. As a user, I should be able to see 4 colored buttons 
2. As a user, I should be able to see the buttons get highlighted on the screen with a sound cue tied to each button
3. As a user, I should be able to keep track of my score while playing the game
4. As a user, I should be able to see my previous high score to try and beat
5. As a user, I should be able to mute/unmute the game sounds 
6. As a user, I should be able to have a fresh set of sequences everytime I play the game
